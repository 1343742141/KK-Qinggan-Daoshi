# KK 情感导师 · 情感工具箱

对标 [dbs 工具箱](../) 的情感版：一个总入口 + 按顺序流程分析的情感子 skill。

## 结构
- `skills/KK情感导师` —— 总入口：按 7 步顺序判断（新手教程 / 任务前路由 / 任务后导航），不知道用哪个就回主入口。
- `skills/qg-*` —— 7 个流程子 skill：

| 流程步 | 子 skill | 作用 |
|---|---|---|
| 1 个人定位 / 个人情感市场定位 | `qg-dingwei` | 你在情感市场的位置与价值 |
| 2 分析目标 | `qg-huaxiang` | 目标对方（女生/男生）画像 |
| 3 分析情敌 | `qg-qingdi` | 情敌可能是一个人，也可能是一个群体/圈子 |
| 4 关系定位 · 你的需求 | `qg-guanxi` | 长期谈恋爱 / 短期在一起 / 婚恋结婚（3类） |
| 5 对方需求分析 | `qg-xuqiu` | 短期关系 / 长期关系 / 婚恋（3类，男女各一套） |
| 6 情敌人群 · 竞争位势 | `qg-qingding` | 谁、几分~几分、什么阶级、会什么技能、怎么差异化 |
| 7 策略生成 | `qg-celue` | 男生需求 × 女生需求 × 情敌需求 → 策略矩阵 |

## 关键设计
- **顺序流程**：所有人进来都按这 7 步走一遍，每步带出「当前关系类型」（婚恋/脱单/高分/挽回 · 短期/长期）。
- **分析维度模板**：分析任何一方（你 / 目标 / 情敌）都套同一套模板 —— 基本盘（出身/学历/职业/成长/情感经历/市场行情/收入/情感策略段位/外形）+ 社交与展示（展示面/长期或短期属性/找漏洞/信息差/性格/社交/可选择面/兴趣爱好/内容消费阶级/内容类型）+ 家庭阶级背景（阶级/家庭情况/家庭构成）。
- **内容原则**：判断标准、策略细节等由 KK 逐条填充（skill 内标【待你补充】处尚未填），此仓库随内容逐步补全。

## 安装
把 `skills/` 下每个目录复制到 `~/.claude/skills/` 即视为安装。
