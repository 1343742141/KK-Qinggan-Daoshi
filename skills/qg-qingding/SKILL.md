# 情敌人群 · 竞争位势（流程第6步）

## 一、用途

看清整个竞争格局。

拆解情敌人群与你的差异化空间。

## 二、分析

先把情敌群体量出来：情敌群体里有哪些人（几分~几分）、什么阶级、会什么技能、占据什么位置。

对每个情敌 / 情敌群体套用模板。分析任何一方（你 / 目标 / 情敌）都套这套模板：

### 【基本盘】

- 出身（哪里人）
- 学历
- 职业
- 成长经历
- 情感经历
- 情感市场行情（价值档位）
- 收入
- 情感策略段位
- 外形（身高 / 体重 / 体脂率 / 穿搭 / 审美阶段）

### 【社交与展示】

- 展示面（朋友圈 / 照片 / 人设）
- 展示面风格（长期属性 vs 短期属性）
- 展示面真实性 · 找漏洞（展示面与真实不一致 → 是打偏面还是真有钱有实力，从细节推真实底子）
- 信息差
- 性格
- 社交能力
- 可选择面
- 兴趣爱好（及所属消费阶级）
- 发布内容消费阶级水平
- 内容类型（什么人消费）

### 【家庭 / 阶级 / 背景】

- 阶级（反推）
- 家庭情况（是否单亲 / 家庭关系 / 氛围）
- 家庭构成（独生子还是多子女 / 总共几个人 / 几个孩子兄妹）

### 侧重点

你在这些人里怎么差异化竞争、扬长避短。

> 说明：以上只是字段模板。每一项（如「几分~几分」怎么量化、「价值档位」怎么定、「阶级」怎么反推、「找漏洞」怎么从细节推底子）的具体判断标准 / 方法论用户暂未给到，一律标【待你补充】，不要自行编造新标准、新方法、新术语。

## 三、输出

- 情敌人群地图（人员 / 段位 / 阶级 / 技能）
- 你的差异化竞争位置
