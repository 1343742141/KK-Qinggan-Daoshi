# 目标分析（流程第2步）

## 一、用途

看清对方（女生或男生）到底是个什么样的人。

## 二、分析

对对方套这套模板，含对方需求判断。

> 分析任何一方（你 / 目标 / 情敌）都套这套模板。

### 【基本盘】
- 出身（哪里人）
- 学历
- 职业
- 成长经历
- 情感经历
- 情感市场行情（价值档位）
- 收入
- 情感策略段位
- 外形（身高 / 体重 / 体脂率 / 穿搭 / 审美阶段）

### 【社交与展示】
- 展示面（朋友圈 / 照片 / 人设）
- 展示面风格（长期属性 vs 短期属性）
- 展示面真实性 · 找漏洞（展示面与真实不一致 → 是打偏面还是真有钱有实力，从细节推真实底子）
- 信息差
- 性格
- 社交能力
- 可选择面
- 兴趣爱好（及所属消费阶级）
- 发布内容消费阶级水平
- 内容类型（什么人消费）

### 【家庭 / 阶级 / 背景】
- 阶级（反推）
- 家庭情况（是否单亲 / 家庭关系 / 氛围）
- 家庭构成（独生子还是多子女 / 总共几个人 / 几个孩子兄妹）

### 侧重点
- 对方处于短期 / 长期 / 婚恋哪种需求
- 从展示面和细节判断真实性、阶级、家庭

## 三、输出

- 目标画像
- 对方需求
- 从展示面反推的底牌
