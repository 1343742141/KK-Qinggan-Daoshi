# 关系定位 · 你的需求（流程第4步）

## 一、用途

先弄清你要的是哪类关系。

定位你自己在这段/目标关系里想要什么。

## 二、分析

你的需求 = 长期谈恋爱 / 短期在一起 / 婚恋结婚（3 类）。

### 3 类

- 长期谈恋爱
- 短期在一起
- 婚恋结婚

### 侧重点

区分你自己是长期取向还是短期取向、是否奔着婚恋。

> 说明：用户给的框架只有「长期谈恋爱 / 短期在一起 / 婚恋结婚」这 3 类，以及「区分长期 vs 短期取向、是否奔着婚恋」这个侧重点。每一项具体怎么判断（比如「怎么区分长期还是短期取向」「某段关系该归到哪一类」）用户暂未给到，一律标【待你补充】，不要自行编造新标准、新方法、新术语。

## 三、输出

你的关系需求定位（长期 / 短期 / 婚恋）+ 一句话说明为什么。
