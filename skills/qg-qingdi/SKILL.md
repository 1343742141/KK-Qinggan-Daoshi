# 情敌分析（流程第3步）

## 一、用途

看清谁在跟你竞争。

情敌可能是一个人，也可能是一个群体/圈子。

## 二、分析

对每个情敌 / 情敌群体套用模板。分析任何一方（你 / 目标 / 情敌）都套这套模板：

### 【基本盘】
- 出身（哪里人）
- 学历
- 职业
- 成长经历
- 情感经历
- 情感市场行情（价值档位）
- 收入
- 情感策略段位
- 外形（身高 / 体重 / 体脂率 / 穿搭 / 审美阶段）

### 【社交与展示】
- 展示面（朋友圈 / 照片 / 人设）
- 展示面风格（长期属性 vs 短期属性）
- 展示面真实性 · 找漏洞（展示面与真实不一致 → 是打偏面还是真有钱有实力，从细节推真实底子）
- 信息差
- 性格
- 社交能力
- 可选择面
- 兴趣爱好（及所属消费阶级）
- 发布内容消费阶级水平
- 内容类型（什么人消费）

### 【家庭 / 阶级 / 背景】
- 阶级（反推）
- 家庭情况（是否单亲 / 家庭关系 / 氛围）
- 家庭构成（独生子还是多子女 / 总共几个人 / 几个孩子兄妹）

### 侧重点
- 情敌是单个人还是群体
- 对方（目标）身边有多少可选择竞争者

## 三、输出

- 情敌清单（个人 + 群体）
- 每个情敌的基本盘与展示面
